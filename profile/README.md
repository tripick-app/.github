# Tripick

**把一趟旅程的照片，整理成值得回看的片段。**

Tripick 是一款 iPhone 旅行照片整理工具。它按拍摄时间归拢照片；照片带有地点信息时，也会参考地点。设备本地分析帮助发现清晰照片、人物状态较好的画面、连拍代表照和相似照片。

## 由你挑选，也由你确认

选择要整理的相册或照片，以及希望保留的数量。复核并调整 Tripick 给出的候选后再确认；只有确认后，Tripick 才会在 Apple Photos 中创建或合并精选相簿，并将选中的照片标记为收藏。Tripick 不会删除或改动原始照片。

## 照片留在 iPhone 上

照片分析在 iPhone 本地完成。照片、缩略图和分析结果不会上传到 Tripick 服务器或第三方云端 AI。
